### Installation [first run only]

A - Check Python version [using 2.7]
    
    $python -V
    
B - Create and Run new venv
    
    $virtualenv venv
    
    $source ./venv/bin/activate
    
    
C - Install requirments
    
    $pip install -r requirments

D - Run Mongo

$monogd | $sudo mongod
